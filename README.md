# Starward Defenders

Static browser game inspired by classic 1970s space-invader arcade design.

## Play

Once GitHub Pages is enabled for this repository, the game will be available at:

`https://reolinturi.github.io/Space_Invaders/`

## Controls

- Move: `ArrowLeft` / `ArrowRight` or `A` / `D`
- Fire: `Space`

## Local Files

- `index.html`
- `styles.css`
- `game.js`
