# Starward Defenders: Cinder Reach

Fly the KX-4 interceptor above Kestrel Station through ten waves of an original arcade campaign. The Three.js scene includes modelled ships, relay masts, an orbital landscape and a ringed planet. Ships, tracers, shield damage and the defense line use the same coordinates as the simulation. Browsers without WebGL can use the arcade view.

[Play Cinder Reach on GitHub Pages](https://reolinturi.github.io/Space_Invaders/)

Move with the arrow keys or A and D. Hold Space to fire. Touch devices have on-screen controls. Both the surviving enemy formation reaching the defense line and the loss of the last hull end the campaign. The flight record can be copied as an illustrated diploma.

## Flight control

The public game carries 40 OpenAI-generated radio transmissions in `transmissions.json`. Flight control selects a briefing, last-life warning, aiming tip or debrief from the current sector. These work on static hosting and public plays incur no API charges.

The local flight server also offers on-demand radio calls through the OpenAI Responses API. **Request intel** sends the wave, remaining ships, lives, score, accuracy, shot count and campaign phase. The model's reply appears below the flight deck. If the uplink is unavailable, the onboard archive supplies the call.

## Local flight deck

From the project directory, use Node.js 24 or later. The default address is [the local flight deck](http://127.0.0.1:8787).

```sh
node control.mjs
```

To enable live radio, run the same command with `OPENAI_API_KEY` in the server environment, or point Node at an existing private env file. For example:

```sh
node --env-file=".env.local" control.mjs
```

The server binds to loopback and serves only public game assets. API requests use `gpt-4.1-mini` by default; `OPENAI_MODEL` selects a different Responses-compatible model. The game does not make automatic live requests. To regenerate the public archive, run the following and publish the resulting JSON with the static site:

```sh
node --env-file=".env.local" control.mjs --archive
```

The bundled Three.js r180 distribution and MIT license are under `vendor/three/`. The ship geometry, terrain and planet textures are generated by the game.
